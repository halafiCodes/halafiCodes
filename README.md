## Selected projects

**[Medical Telegram Data Warehouse](https://github.com/halafiCodes/Medical_telegram_warehouse)**
End-to-end ELT product over public Ethiopian medical Telegram channels. Telethon ingestion → PostgreSQL → dbt star schema → YOLOv8 image enrichment → FastAPI analytical API, orchestrated with Dagster and containerized with Docker.

**[Credit Risk Model](https://github.com/halafiCodes/credit-risk-model)**
Basel II–oriented credit scoring model. Builds an RFM-based proxy target where no default label exists, then compares WoE + Logistic Regression against gradient boosting to weigh interpretability against predictive performance.

**[Project Chimera](https://github.com/halafiCodes/Agentic_Infrastructure_26)**
Spec-driven foundation for an autonomous agent system — functional and technical SRS, MCP tool schemas, and architecture decision records, with implementation deliberately held until specs are ratified.

**[Fraud Detection](https://github.com/halafiCodes/fraud-detection)**
Classification pipeline for fraudulent transactions on heavily imbalanced data.

**[Insurance Risk Analytics](https://github.com/halafiCodes/Insurance_Risk_Analytics_Predictive_Modeling)**
Predictive modeling and hypothesis testing over insurance claims data to inform pricing.

**[Football Player Tracking](https://github.com/halafiCodes/football_taracking_computer-_vision)**
Player and ball detection and tracking in match footage using YOLO.
